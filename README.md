## 📖 Overview

This repository contains the complete source code for the official portfolio website of **Faizul Islam Rifat**. Built with modern semantic HTML5, glassmorphic CSS3 styling, and modular JavaScript, this website serves as a high-converting digital storefront showcasing video production case studies, digital marketing funnels, web development work, and client testimonials.

---

## ✨ Key Features

- **🌓 Dynamic Dark / Light Mode:** Smooth theme transitions with customizable neon/glass tokens.
- **🌐 Full Bilingual Support (English & বাংলা):** Instant real-time language switcher without page reloading.
- **📱 100% Mobile Responsive:** Fluid layouts designed for mobile, tablet, and widescreen desktop displays.
- **💎 Glassmorphic & Mesh Aesthetic:** Modern cyber-neon aesthetics, subtle mesh blurs, and micro-animations.
- **💼 Interactive Case Studies & Modals:** Clickable pop-up modals displaying in-depth challenges, strategies, and measurable ROI metrics for client projects.
- **🎉 Interactive Contact & Confetti:** Validated contact booking form with celebration confetti effects and direct WhatsApp integration.

## 🛠️ Built With

* **HTML5:** Semantic architecture with modern SEO meta tags.
* **CSS3:** Custom CSS variables, Flexbox, Grid, backdrop-filter glassmorphism, and neon gradients.
* **JavaScript (Vanilla ES6+):** Lightweight DOM manipulation, localStorage caching, dynamic translation rendering.
* **External Libraries:**
  * [Font Awesome 6](https://cdnjs.com/libraries/font-awesome) — Vector iconography.
  * [Google Fonts](https://fonts.google.com/) — *Inter*, *Outfit*, and *Noto Sans Bengali*.
  * [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) — Celebration effects on form submission.

## 🚀 Quick Start / How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/faizulislamrifat/faizul-islam-rifat-portfolio.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd faizul-islam-rifat-portfolio
   ```

3. **Open the site:**
   - Simply double-click **`index.html`** to launch it in any modern web browser (Chrome, Edge, Firefox, Brave, Safari).
   - Or use VS Code's **Live Server** extension for hot-reloading.
